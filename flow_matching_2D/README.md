# Flow Matching for Applied Mathematicians – 2D Codes

## Author: Emile Pierret

This repository contains 2D experimental codes associated with the paper  **Flow Matching for Applied Mathematicians**. It implements the Flow Matching algorithm on simple 2D examples, with the goal of illustrating and facilitating the understanding of the main concepts introduced in the paper. The repository is organized into five Jupyter notebooks, whose purposes are summarized below:

- **1_closed_form.ipynb**  
  Reproduces figures using explicit velocity fields (Gaussians, Gaussian Mixture Models, and Gaussian-to-Dirac-sum settings).

- **2_scheduler.ipynb**  
  Compares cosine and linear time schedules on exact velocity fields.

- **3_training.ipynb**  
  Trains a velocity field on 2D datasets.

- **4_rectification.ipynb**  
  Performs rectification iterations.

- **5_Mini_batch_OT.ipynb**  
  Implements mini-batch Optimal Transport training for Flow Matching.
