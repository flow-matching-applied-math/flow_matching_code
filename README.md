## Overview

This repository provides reference implementations of Flow Matching methods aimed at an applied mathematics audience. The code illustrates both low-dimensional toy problems and high-dimensional image data, highlighting theoretical concepts as well as practical implementation details.

## Repository Structure

The repository is organized into two main components:

- **`flow_matching_2D/`** — Implementation of Flow Matching for two-dimensional toy datasets (visualization, trajectories, velocity fields, etc.)
- **`flow_matching_image/`** — Implementation of Flow Matching for image data

Each subdirectory contains its own documentation with detailed instructions on installation, usage, and experiments.

➡️ Please consult the README file in each subfolder for task-specific guidance.
